## ✨ Features

- 🌑 **Dark glassmorphism theme** with purple & cyan accents
- 🎇 **Animated particle canvas** background (constellation effect)
- ✍️ **Typewriter effect** cycling through roles
- 🖱️ **Custom cursor** with smooth follower animation
- 📊 **Animated skill progress bars** triggered on scroll
- 🃏 **3D card tilt effect** on hover
- 📱 **Fully responsive** — works on mobile, tablet & desktop
- ⚡ **Zero dependencies** — pure HTML, CSS & JavaScript

## 🚀 How to Run

No installation or server required!

1. Clone or download this repository
2. Open the folder
3. **Double-click `index.html`**
4. It opens directly in your browser ✅

```bash
# Or clone via Git
git clone https://github.com/Samarthdhamija007/portfolio.git
cd portfolio
# Open index.html in your browser
```
